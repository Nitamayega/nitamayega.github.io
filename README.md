# 🌟 Portfolio Website - Nitamayega

Website portfolio personal yang menampilkan profil, proyek, dan pengalaman sebagai Mobile Developer. Dibuat sebagai submission untuk Tugas Akhir Membuat Website di Dicoding Academy.

## 📋 Deskripsi

Website portfolio ini menampilkan informasi lengkap tentang Nitamayega, seorang lulusan S1 Informatika dari Universitas Telkom dengan IPK 3,86. Website ini menampilkan keahlian dalam bahasa pemrograman Kotlin, Python, dan Golang, serta pengalaman sebagai Mobile Developer. (Not Updated)

## ✨ Fitur

- **Responsive Design**: Website dapat diakses dengan baik di berbagai perangkat (desktop, tablet, mobile)
- **Dark/Light Mode**: Toggle untuk mengubah tema tampilan
- **Navigasi Smooth**: Navigasi halus antar section
- **Form Feedback**: Form interaktif untuk feedback pengunjung
- **Portfolio Projects**: Showcase proyek-proyek yang telah dikerjakan
- **Professional Experience**: Timeline pengalaman kerja dan pelatihan

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur halaman web
- **CSS3**: Styling dan layout responsive
- **JavaScript**: Interaktivitas dan toggle dark mode
- **Font Awesome**: Icon library
- **Google Fonts**: Typography (Source Code Pro)
- **SweetAlert2**: Pop-up notification yang menarik
